# Study Library Management Demo

A browser-based demonstration of study library operations for prospective clients.

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Lucide icons
- Browser localStorage for demo persistence (planned)

## Local development

Requirements: Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Demo-only notice

This project is a frontend demonstration. It is not intended for real student records, real payments, or production library operations. Do not enter sensitive personal information.
